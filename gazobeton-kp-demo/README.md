# Дом из газобетона: интерактивное КП за минуты

Демонстрация конвейера «заявка → КП»: расчёт газобетона, эскизные чертежи, 3D с мебелью, раскладка блоков, логистика и заявка на счёт для частного дома.

Три сценария входных данных:

1. **Ничего нет** — только размеры: дом 6×9, Копейск.
2. **Набросок от руки** — дом 8×10, с. Вознесенка.
3. **Проект из интернета** — свой проект Г-210, 206,5 м², Магнитогорск.

Сайт: https://kilevoy.github.io/gazobeton-kp-demo/
