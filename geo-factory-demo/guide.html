Как работать с GEO Factory

Инструмент ведёт шестинедельный пилот: проверяет на фактах, приводят ли экспертные материалы завода покупателей из поиска Яндекса и ответов нейросетей.

Главное правило

Каждая цифра в интерфейсе имеет статус. «Вордстат» — число, снятое в сервисе, с датой. «Демо-оценка» — ориентир, заданный вручную; таких в ядре сейчас нет. Спрос в инструменте реальный, а экономика — модель: конверсии и цену задаёте вы.

1Обзор

Четыре показателя готовности пилота и список ближайших шагов. Кнопка «Печать сводки» даёт одну страницу А4 для руководителя.

2Спрос

Ядро собрано из запросов, которые люди действительно вводят в Яндексе: 50 запросов в 7 кластерах, частоты сняты в Вордстате по Челябинской области и Уралу.

  • Частота — число запросов в месяц по широкому соответствию: в «купить газоблок» входят и «купить газоблок в челябинске», и «купить газоблок цена».
  • Итог кластера считается только по якорным запросам, иначе вложенные запросы посчитались бы дважды. Это верхняя оценка.
  • Раз в месяц обновляйте числа: кнопка «Вордстат ↗» у запроса открывает его в сервисе, новое значение вводится прямо в таблицу. Для всего ядра удобнее «Скачать таблицу CSV» → исправить в Excel → «Загрузить CSV».

Внизу раздела — архив первой версии ядра: 60 длинных фраз, по 57 из которых спроса нет. Это напоминание, почему темы выбирают по Вордстату, а не по ощущению.

3Выдача

  1. Откройте окно инкогнито и нажмите «Яндекс ↗» у запроса.
  2. Найдите сайт завода и выберите его позицию: место среди первых 12 органических результатов, рекламные блоки не считаются. Если сайта среди них нет — «нет в топ-12».
  3. Посмотрите блок «Быстрый ответ ИИ» над выдачей (раньше он назывался Нейро) и отметьте, есть ли завод среди источников или в тексте.
  4. Запишите, кто стоит на первом месте: это список тех, с кем предстоит конкурировать.

Запросы для замера взяты из гипотез и имеют реальный спрос. Через шесть недель переключитесь на «Повторный замер» и пройдите те же запросы. Карточки наверху покажут «было → стало».

4Экономика

Калькулятор считает путь: целевые запросы → дополнительные переходы → обращения → отгрузки → выручка и маржа. Спрос подставляется из раздела «Спрос», остальное — допущения, которые вы двигаете ползунками.

Обязательно введите годовую отгрузку завода. Инструмент сравнит результат модели с фактом и предупредит, если допущения завышены.

5Контент

ВкладкаЧто в ней
СтатьяТекст для публикации. Жёлтые метки [ПОДТВЕРДИТЬ] — данные, которые знает только завод.
Проверка структурыДесять факторов, по которым нейросети выбирают текст для цитирования. Балл не говорит о достоверности.
Цифры на подтверждениеВсе числовые утверждения текста. Распечатайте и отдайте инженеру, затем отметьте проверенные.

Статус «Подтверждено инженером» нельзя поставить, пока в тексте есть метки [ПОДТВЕРДИТЬ].

6План пилота

Девять шагов на шесть недель и семь гипотез о темах материалов, отсортированных по реальному спросу.

Где хранятся данные

Всё, что вы вводите, сохраняется в этом браузере на этом компьютере и никуда не передаётся. Чтобы не потерять работу или перенести её на другой компьютер, пользуйтесь кнопками «Сохранить в файл» и «Загрузить из файла» в левой панели.

Для того, кто обновляет данные

  • Обновлённые частоты для всех: сохраните таблицу как data/wordstat_real.csv и запустите python export_data.py. Новые запросы добавляются в src/data/real_core.json.
  • Новая статья: файл в articles/, строка в списке PACKS в export_data.py, запись в articles/reviews.json.
  • Статус проверки статьи для всех: поле status в articles/reviews.json.
  • Файл web/factory_data.js вручную не правится — он собирается скриптом.
