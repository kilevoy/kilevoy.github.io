Методологическая база знаний и AI-скиллы (Book-Skills)

Инженерия знаний · Claude Code & Codex · GitHub Open Source

AI-скиллы на базе мировых бестселлеров по B2B-продажам и управлению

Оцифровка фундаментальных методологий в прикладные инженерные навыки (Skills) для языковых моделей. Модель не выдаёт абстрактные шаблоны, а действует по строгим алгоритмам, конспектам глав и шпаргалкам из книг:

  • «СПИН-продажи» (Нил Рэкхем): методология больших B2B-сделок, перевод скрытых потребностей в явные через цепочку извлекающих вопросов, предотвращение ценового торга.
  • «Никаких компромиссов» (Крис Восс): тактическая эмпатия, защита маржи завода, калиброванные вопросы и модель торга Аккермана против агрессивных отделов снабжения.
  • «Цель» (Элияху Голдратт): Теория ограничений систем (TOC), синхронизация сбыта с ПТО и производством, выявление и расшивка «узких мест».
  • «Спроси маму» (Роб Фитцпатрик): методология проверки спроса (CustDev) при выводе новых линеек продукции завода (фасады, газобетон, профили ГПС).
  • «Пиши, сокращай» (Максим Ильяхов): строгий инфостиль в коммерческих предложениях и деловой переписке без канцелярита и пустых штампов.
  • «Атомные привычки» (Джеймс Клир): системное внедрение регламентов и стандартов CRM без саботажа в отделе продаж.
